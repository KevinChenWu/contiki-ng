# automated-simulation-scripts

Required packages:
- Expect (command to install: `sudo apt install expect`)

## automated-interactive-cooja

Usage of `automated_interactive_cooja.exp`:

    >./automated_interactive_cooja.exp <full path to contiki-ng> <full path to contiki-ng/examples/*simulation*> <CSC file to simulate> <first group of IPv6 address to be used> <Listen port for RPL Border Router to connect> <random seed for the simulation of CSC file>
